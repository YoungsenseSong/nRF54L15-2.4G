# 工程指标与接口规格

## 1. 目标

| 指标 | 目标值 | 验收方法 | 当前结果 | 状态 |
|---|---:|---|---:|---|
| 生产无线帧格式 | 204 B | 源码和 CRC 检查 | 已保留 | ☑ |
| 同步广播周期 | 100 ms | 协调器 UART/原始日志 | 已构建 | ☑ |
| 响应端硬件起点 | RADIO ADDRESS + TIMER20 | DPPI/GPIOTE 配置和示波器 | RX1→RX2 协议窗口通过 | ☐ |
| 双响应端共同轮次 | RX2 + TX1 | 两端状态和同仪器边沿 | TX1 尚未完成 | ☐ |

## 2. 功能指标

- TX：IIM-42352 采样、批次共享内存、CRC32、ESB 发送。
- RX：帧校验、序号/缺口统计、可选 SPIS/FIFO/FMC 传输。
- 同步协调器：共同 `epoch/sequence`、响应端硬件定时和可观察脉冲。

## 3. 接口定义

| 接口/信号 | 方向 | 位宽 | 电平/协议 | 时序要求 | 备注 |
|---|---|---:|---|---|---|
| ESB | 双向 | 无线 | Nordic ESB | channel 40 原型 | 生产 RX/TX 参数另见应用文档 |
| SPI/DRDY/SYNC | RX↔FPGA | 多线 | 3.3 V，SPI | 当前 RX 配置 | 不由同步原型改变 |
| P1.09 | 响应端输出 | 1 | GPIO | TIMER 比较事件 | 仅测试点，禁止盲接 |
| UART | 板→主机 | 1 | 115200 | 状态输出 | 不作为微秒同步测量 |

## 4. 时钟与复位

生产采集由 nRF HF 时钟和 IIM 配置决定；同步原型的 TIMER20 使用 1 MHz 配置，实际精度取决于 HFCLK/HFXO。

## 5. 资源、性能和环境约束

- 使用 Nordic Connect SDK/Zephyr 和 nRF54L15 CPUAPP/FLPR。
- 不把主机 UART 调度延迟计入板上同步精度。
- 构建目录、烧录日志和探针原始镜像不作为源代码交付。

## 6. 验收标准

1. RX/TX 工程可按仓库脚本构建。
2. 同步协调器和响应端可分别构建。
3. RX1→RX2 窗口中轮次、序号和响应事件持续增长。
4. 双响应端和物理边沿测量完成后，才评估同步精度。
